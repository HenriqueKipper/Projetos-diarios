# Projetos Diários de Programação

Este repositório reúne os projetos que desenvolvo diariamente para praticar programação e evoluir minhas habilidades como desenvolvedor.

## Objetivo

Desenvolver um projeto por dia, com duração aproximada de **1 hora**, para aprender novos conceitos, praticar a resolução de problemas e ganhar experiência escrevendo código.

## Como funciona?

- Um novo desafio de programação por dia;
- Projetos de nível iniciante, com dificuldade crescente;
- Exercícios em Python e, ocasionalmente, em outras linguagens;
- Implementação prática dos conceitos estudados;
- Registro da minha evolução por meio do código publicado neste repositório.

## Organização

Cada projeto possui seus próprios arquivos e pode abordar um tema diferente, como automação, jogos, ferramentas de terminal, manipulação de dados e pequenos sistemas.

## Progresso

Este repositório também serve como um registro da minha jornada de aprendizado, mostrando minha evolução, as soluções que desenvolvi e os conceitos que estou aprendendo ao longo do tempo.
